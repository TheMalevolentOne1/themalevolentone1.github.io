API access is free for **development purposes** (using the [**Delayed App Key**](https://support.developer.betfair.com/hc/en-us/articles/360009638032-How-when-should-I-use-the-Delayed-Live-Application-Key-)) for **private** betting customers and **licensed software vendors**.

A one-off activation fee of **£299** applies for Live App Key access for betting purposes.  This is debited directly from your Betfair account once access is approved.  Activation fees are non-refundable.  **Please note: Read-only** access via the Live App Key isn't permitted.

Please see **[Personal Betting Access - Application Key Overview](https://docs.developer.betfair.com/display/1smk3cen4v3lu3yomq5qye0ni/Application+Keys#ApplicationKeys-PersonalBettingAccess-ApplicationKeyOverviewPBA)** for further information.

**[Which license do I require](https://support.developer.betfair.com/hc/en-us/articles/360002464152-Which-API-Licence-do-I-require-)** indicates the process to follow based on your specific intended API usage.
