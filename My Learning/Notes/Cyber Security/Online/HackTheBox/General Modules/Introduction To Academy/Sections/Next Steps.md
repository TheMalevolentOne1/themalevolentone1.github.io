# Pick a Path

To begin the journey of HTB it is recommended to always follow a specific path in the learning journey. 

If the user is a beginner, just beginning the cybersecurity journey then it is recommended to begin enrolling in the Information Security Foundations path. A skill path that will prepare the user for their first HTB certification regardless of current skill level.

`Image of Information Security Foundations Path`

If the user has some experience within cybersecurity then the Penetration tester bath is recommended as the first certification in the intermediate job roles path.

`Image of Penetration Tester Path`

`Image of Bug Bounty Hunter`

`Image of SOC Analyst`

If the user is highly experienced in cyber security and would like to get into an advanced specific field it is suggested to enrol in one of the advanced job paths including the following:
- Senior Web Penetration Tester

`Image of Senior Web Penetration Tester Path`

- HTB Certified Web Exploitation Expert

`Image of HTB Certified Web Exploitation Expert Path`

- Active Directory Penetration Tester

`Image of Active Directory Penetration Tester Path`

HTB Academy plans to keep pushing more modules, paths and certifications moving forward.
