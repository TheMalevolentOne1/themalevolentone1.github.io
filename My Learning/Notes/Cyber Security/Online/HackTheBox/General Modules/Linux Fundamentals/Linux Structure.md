# Linux Structure
Linux is that it is open-source operating system used in pcs, servers and even some mobiles, known for being robust, flexible.

Linux is an OS just like Windows, MacOS, or Android. An OS is simply software that communicates, maintains and handles all hardware resources on a computer. However, Linux has a significantly steeper learning curve than other operating systems which may be a challenge for beginners.

Unlike the other aforementioned OS' Linux comes in many different distribution often referred to as `distros` which are versions (available over 600+ distributions (Utilising the Linux kernel)) of Linux tailored, to serve a specific need or purpose.

Considered more safe than other operating systems, it has had many kernel vulnerabilities, fortunately this is becoming less and less frequent. Linux is also less susceptible to malware than Windows OS' and is frequently updated.

# History of Linux
## Unix Operating System
The Unix OS was released by [Ken Thompson](https://en.wikipedia.org/wiki/Ken_Thompson) and [Dennis Ritchie](https://en.wikipedia.org/wiki/Dennis_Ritchie) in 1970. When releasing the [Berkeley Software Distribution (BSD)](https://en.wikipedia.org/wiki/Berkeley_Software_Design) which was released in 1977. However, in the early 1990s a [lawsuit](https://en.wikipedia.org/wiki/UNIX_System_Laboratories,_Inc._v._Berkeley_Software_Design,_Inc.) arose from AT&T due to their ownership of the Unix code that project utilised.

>[!info] Fun Fact
>[Richard Stallman](https://en.wikipedia.org/wiki/Richard_Stallman) started the [GNU](https://en.wikipedia.org/wiki/GNU) project in 1983, aiming to create a Unix-like operating system, and part of his work resulted in the creation of the [GNU General Public License (GPL)](https://en.wikipedia.org/wiki/GNU_General_Public_License) being created.
## The Beginning of Linux
At first, Linux was a project started in 1991 by [Linux Torvalds](https://en.wikipedia.org/wiki/Linus_Torvalds). Over the years the Linux kernel has gone from a small number of files written in C under licensing that prohibited [commercial distributed] to the latest version with over 23 million source code lines (with comments excluded) licensed under the [GNU Public License V2]
