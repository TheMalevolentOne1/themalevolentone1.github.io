[[Digging DNS (DNS Tools & Techniques)]]

|                    Online LookUp Tool                     |                                  Description                                  |                        Features                         |
| :-------------------------------------------------------: | :---------------------------------------------------------------------------: | :-----------------------------------------------------: |
|     [MXToolbox](https://grok.com/chat/mxtoolbox.com)      |         Offers DNS lookup, blacklist checks, and MX record analysis.          |   Tools for DNS health, SPF, and DMARC verification.    |
| [Google Public DNS](https://grok.com/chat/dns.google.com) | Simple interface for querying DNS records using Google's public DNS resolver. |           Supports A, AAAA, MX, NS, and more.           |
|           [DNSChecker](https://dnschecker.org)            | Provides global DNS propagation checks and lookup for multiple record types.  |   Allows checking from various geographic locations.    |
|            [nslookup.io](https://nslookup.io)             |        Clean interface for querying A, MX, NS, TXT, and other records.        |            Includes WHOIS and DNSSEC checks.            |
|           [WhatsMyDNS](https://whatsmydns.net)            |               Focuses on DNS propagation across global servers.               | Supports multiple record types with a simple interface. |
|            [Dig](https://digwebinterface.com)             |          Mimics the command-line dig tool for detailed DNS queries.           | Supports advanced options like specifying DNS servers.  |
|  [Cloudflare 1.1.1.1 Tools](https://cloudflare.com/dns)   | Offers DNS lookup and diagnostic tools tied to Cloudflare’s 1.1.1.1 resolver. |               Simple and privacy-focused.               |
