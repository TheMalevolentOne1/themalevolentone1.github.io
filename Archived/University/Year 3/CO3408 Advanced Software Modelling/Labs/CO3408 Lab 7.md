## Part 2 - Thread Priorities (Demonstration)
>[!EXAMPLE] Task 2.1 - Experiment with Priorities

>```java
>thread.setPriority(1 + (int)(Math.random()*10));
>```
>Run the program multiple times with this thread demo.
> > [!EXAMPLE] Code Example
> >```java
> >public class ThreadPriorityDemo
> >{
> >	public static void main(String[] args)
> >	{
> >		//Create and start 5 threads with random priorities
> >		for (int i = 1; i <= 5; i++)

## Part 4 - Implementing a Producer-Consumer in Java
>[!EXAMPLE] Task 4.1 - Implement a Shared Buffer
>Create a class `Buffer` with:
>- A fixed-size array (size = 5)
>- produce(item) method
>- consume() method
>
> > Use `synchronized`, `wait()`, `notifyAll()`

>[!EXAMPLE] Task 4.2 - Implement Producer and Consumer Threads
>Create the following:
>- Producer implements Runnable
>- Consumer implements Runnable  
>- Producer - Generates 10 items
>- Consumer - Consumes 10 items
>
>Start both threads from a `main()` method.
> >[!EXAMPLE] Code Example
> >```java
> >public class ProducerAndConsumer
> >{
> >	public static void main(String[] args)
> >	{
> >		Buffer buffer = new Buffer();
> >		new Thread(new Producer(buffer)).start();
> >		new Thread(new Consumer(buffer)).start();
> >	}
> >}
> >
> >class Buffer
> >{
> >	private String[] items = new String[5];
> >	private int count = 0;
> >	
> >	private sychronized void produce(String item)
> >	{
> >		while (count == items.length)
> >		{
> >			try 
> >			{ wait(); } 
> >		}
> >		
> >		items[count++] = item;
> >		notifyAll();
> >	}
> >	
> >	public synchronized String consume()
> >	{
> >		while (count == 0)
> >		{
> >			try { wait(); }
> >		}
> >		String item = items[--count];
> >		notifyAll();
> >		return item;
> >	}
> >}
> >```
