# Additional Research
[Perceptron](https://www.youtube.com/watch?v=ZhF4gV-Be8Q)
The perceptron is a simple building block for neural networks that classify patterns that are *linearly separable*.

The data can be divided into two distinct classes separated by a 'hyperplane' in higher dimensions, which act as a decision boundary.

However, if the classes become too close or overlay they become non-linearly separable, therefore rendering the perceptron inefficient for this activity.

Perceptron consists of a single neuron with adjustable synaptic weights and bias.

The perception algorithm first introduced by Frank Rosenblatt in 1958, adjusts the parameters during training.

Rosenblatt proved that if patterns used to train the perceptron are from two linearly separable classes then the perceptron algorithm will successfully converge and position the hyperplane accurately between the two classes.

A perceptron is a type of artificial neuron used in machine learning, it simulates the way a single biological neuron processes inputs and produces an output. 

The perceptron is the simplest form of a neural network.
## Key Components
- Inputs (Features) - The data which is fed into the model. E.g. Hours Studied and Hours Slept
- Weights - The important assigned to each input
- Bias - Adjusts the output to make better predictions
- Output - The perceptron's prediction E.g. Pass or Fail
## Perceptron
```python
# Perceptron Function
def perceptron(inputs, weights, bias):
	weighted_sum = sum(x * w for x, w in zip(inputs, weights)) + bias
	return 1 if weighted_sum >= 0 else 0
	
# Inputs and Parameters
inputs = [4, 3] # Hours studied and slept
weights = [0.6, 0.4]
bias = -0.5

# Prediction
output = perceptron(inputs, weights, bias)
print("Predicted (Pass = 1, Fail = 0): ", output)
```
The weights determine the **slope** of the line whereas the *bias* determines where the line sits on the x-axis shifted from the centre.
- Without biases the decision line is placed at 0,0 origin point but it is unable to adjust.
- With bias the line can be unpinned and shifted to best fit.

### Visualizing the Decision Boundary
```python
import numpy as np
import matplotlib.pyplot as plt

# Paraneters
weights = np.array([0.6, 0.4])
bias = -0.5

# Decision Boundary
# w1*x1+w2*x2+b=0
x1 = np.linspace(0,10,100)
x2 = -(weights[0] * x1 + bias) / weights[1] # Solve for x2

# Plot Data Points
plt.plot(x1, x2, label="Decision Boundary")
plt.fill_between(x1, x2, 10, color="lightblue", alpha=0.5, label="Pass Region")
plt.fill_between(x1, x2, 0, color="lightcoral", alpha=0.5, label="Fail Region")
plt.scatter(4, 3, color="green", label="Student (4 hrs study, 3 hrs sleep)")
plt.xlabel("Hours Studied")
plt.ylabel("Hours Slept")
plt.title("Perceptron Decision Boundary")
plt.legend()
plt.show()
```
Decision Boundary - The line where the perceptron switches its decision between pass and fail.
Blue Region - Represents where students pass.
Red Region - Represents where students fail.
Green Dot - Represents the specific student (4 hours studied, 3 hours slept) that was predicted.

        for i in range(len(X)):
            linear_output = np.dot(X[i], weights) + bias
            y_pred = activation(linear_output)
  
            # Calculate error
            error = y[i] - y_pred
  
            # Update weights and bias
