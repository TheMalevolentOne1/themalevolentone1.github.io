## Python with NumPy & Important Data Types
NumPy is the core library for scientific computing in Python.
### Importing Package
```python
import numpy as np
```
<sub>Importing the NumPy package.</sub>
### Arrays
A **NumPy array** is basically a table (or grid) of numbers that are **all the same data type** (for example, all integers or all floats).

- Each value in the array can be located using **indexes** — numbers that tell you where the value is along each axis (like row and column numbers in a spreadsheet).
- The **number of axes** an array has (for example, 1D, 2D, 3D, etc.) is called its **rank** or **number of dimensions**.
- The **shape** of the array is a **tuple** (a list of numbers in parentheses) that tells you **how big the array is in each dimension**.
```python
a = np.array([1, 2, 3])
```
<sub>One Dimensional NumPy Array</sub>
```python
b = np.array([[1,2,3],[1,2,3]])
```
<sub>Two Dimensional NumPy Array</sub>
#### NumPy Functions to Create Arrays
```python
a = np.zeros((2,2))
```
<sub>Creates array of all zeros</sub>
```python
a = np.ones((1,2))
```
<sub>Creates array of all ones</sub>
```python
a = np.full((2, 2), 7)
```
<sub>Create a consistent array</sub>
#### Assigning DataTypes
```python
x = np.array([1,2]) # Let NumPy Choose DataType
y = np.array([1.0, 1.0]) # Let NumPy Choose DataType
z = np.array([1, 2], dtype.np.int64) # Forcing Array To 64-bit Integer DataType

print(x.dtype, y.dtype, z.dtype)
```

### Plotting
```python
# Compute the x and y coordinates for points on a sign curve
x = np.arange(0, 3 * np.pi, 0.1)
y = np.sin(x)

# Plot points
plt.plot(x,y)
```
