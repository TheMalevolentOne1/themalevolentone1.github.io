# Design and Implementation Deliverable
- In total only around 3000 words expected (+/- 20%)
  - Squeeze to say everything you want to say with this amount of space if have taken a structured approach to design
  - In this case, Appendices are your friend!
  - Diagrams do not count towards your word count
    - lots of diagrams means more pages
    - Summarise key points and design decisions in your report
      - Expand on them in appendices

> Design - This section will present an analysis of the project's requirements and provide a specification for a solution that attempts to meet those requirements. The section should provide a design outline that is appropriate for ur project. (e.g. System Architecture, Network Architecture, UML Diagrams, etc). This section should also briefly discuss the development methodology that has been used.

# Architectural Design
- Part of System Design
- Can provide an overview of the wider context that the system is situated in?
  - A bugger picture than just code
  - e.g.  
    - Does the network consist of multiple components
    - Does the mobile app interact with other pieces of hardware on the phone
      - Camera, Accelerometer, External Database, Cloud Service, etc
    - Does the web app have multiple components
      - HTML Server, PHP Interpreter, Frontend, Backend, Database
