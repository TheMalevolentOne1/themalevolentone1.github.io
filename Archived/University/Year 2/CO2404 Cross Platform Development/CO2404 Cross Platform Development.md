# Module Overview
Module lead: **Dr Mark Lochrie** ([MLochrie@uclan.ac.uk](mailto:MLochrie@uclan.ac.uk)) **-** Senior Lecturer in Computer Science, Course Leader MSc User Experience

Introducing students to cross-platform development for mobile applications; ecosystems, and programming environments through a studio-like design-based approach to practical lab sheets involving the building blocks to mobile application development. 

This module will cover:
- introduction and background to cross-platform development
- Learning Dart programming
- Understanding how Flutter works with various Widgets
- Building User Interfaces with Flutter
- Apply a TDD approach to your workflow
- Learn the best practices for building UIs
- Discover how to evaluate UI and interactions
- Explore how UX techniques can be used to improve and satisfy users
- Extend your knowledge of building software with exchanging data (network)
- Learn how to program using asynchronous techniques 
- Build applications to handle data and user interactions
- Learn about the backend infrastructures that serve cross-platform applications
- Gain an introduction to prototyping

The assessment for this module consists of:
- Exam 40%: 1.5 hours
- Coursework 60%: 2000 words
