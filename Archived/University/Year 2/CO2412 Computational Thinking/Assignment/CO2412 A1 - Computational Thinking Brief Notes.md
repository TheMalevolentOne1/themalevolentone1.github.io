Tasks:

Task 1: ✔️

1. Real-World Data Simulation: 
Write a Python script to generate two simulated datasets representing real-world data: 
a) Dataset 1: Random data (completely random order). ✔️
b) Dataset 2: Reversed data (data sorted in descending order). ✔️

The datasets should contain sizes of 10,000, and 100,000 elements (4 datasets in total). Each generated number should have 6 digits ranging from 100,000 to 999,999. ✔️

Task 2: ✔️

2. Implement Sorting Algorithms: 
Implement the following sorting algorithms in Python and use them to sort the datasets in Task 1: 
c) Merge Sort ✔️
d) QuickSort ✔️

Each sorting algorithm should save its sorted array output to a text file. You can use either a single file or multiple files for this purpose.  ✔️

If using a single file, ensure it is clear which section corresponds to each sorting algorithm and dataset. (**N/A**) (Multiple Files)

Task 3: ✔️

3. Performance Analysis of sorting algorithms: 
Measure and analyse the following performance metrics for each sorting algorithm (Merge Sort and Quick Sort) and dataset sizes including: 
a) Execution Time: (in milliseconds) for sorting each array. ✔️
b) Memory Usage: (in kilobytes) for sorting each array. ✔️
c) Number of Comparisons: (swaps) made during the sorting process. ? ✔️

Task 4: ✔️

4. Graphical Comparison: 
Create graphs (e.g., line charts or bar charts) that compare the runtime performance of the sorting algorithms across different dataset sizes. ✔️

Implement this comparison using Python to visualise how the algorithms perform as data scales. ✔️

The graph/graphs should include Part 3a, 3b and 3c (Execution Time, Memory Usage, Number of Comparisons) ✔️
